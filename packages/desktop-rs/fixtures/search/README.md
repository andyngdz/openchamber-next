# Search fixtures

Input and expected output of the picker search port (`packages/desktop-rs/crates/oc-state/src/search/`),
generated by `packages/desktop-rs/tools/gen-fuse-fixture.mjs`. Regenerate with:

```bash
node packages/desktop-rs/tools/gen-fuse-fixture.mjs
```

The script holds the corpus and the query set in its source, loads Fuse.js 7.1.0 through
`createRequire` from `packages/ui`, and imports the React implementation
`packages/ui/src/lib/search/fuzzySearch.ts` directly. That file imports only Fuse.js, so Node's
TypeScript type stripping runs it: Node 22.18 and later do so by default, older 22.x need
`--experimental-strip-types`. It replaces the two `*.json` files here (this README stays), holds
both outputs in memory, and exits non-zero, writing nothing, if a home directory, the repository
root or a user-name path segment would appear in a file.

The output is deterministic: no ids, timestamps or paths, and one fixed order for the corpus and
the queries. Running the script twice writes byte-identical files.

## Files

| File | Content |
| --- | --- |
| `fuse.json` | `corpus`, the Fuse options `rankByQuery` passes, and per query every Fuse result as `{refIndex, score}` |
| `rank.json` | `corpus` and per query the `rankByQuery` result indices (`ranked`) and the `matchesRankQuery` answer for every corpus entry (`matched`) |

`fuse.json` pins the Fuse port alone: the Rust test compares result indices and order exactly and
scores within `2 * f64::EPSILON * max(|a|, |b|)`, the one-`pow` bound design.md "Testing" derives.
`rank.json` pins the whole pipeline, including the fuzzy fallback and the compact matching, against
React itself.

The corpus mixes project labels, paths, branches, model and provider names and agent names, with
Vietnamese, Cyrillic, Latin-diacritic, Japanese and astral characters and one blank entry, so
lowercasing, UTF-16 positions and Fuse's blank-document skip all appear. The queries cover typos,
short and punctuation-only tokens, multi-token and non-ASCII queries, an empty query, and two
queries longer than Fuse's 32-code-unit pattern chunk.
